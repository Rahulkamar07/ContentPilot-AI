## 1. Copyright & Fair Use Transformation Analysis

Directly reposting news photographs collected from external press publications constitutes copyright infringement under international intellectual property law.

### ContentPilot AI Legal Transformation Guarantee
To eliminate copyright risk, ContentPilot AI enforces a **Transformative Synthesis Protocol**:

```
Source Press Photo -> Multimodal Vision Model -> Textual Scene Breakdown -> Original AI Prompt -> FLUX/SDXL Render
```

1. **No Pixel Copying**: The system never stores, re-hosts, or publishes source news image binaries to public social feeds.
2. **Transformative Artwork**: The output is an original 8k editorial illustration generated by a diffusion model inspired by the scene breakdown, satisfying Fair Use transformative work standards under US Copyright Act (17 U.S.C. § 107).

## 2. Scraping & Robots.txt Compliance Protocol

Playwright and HTTP scrapers strictly observe web crawling ethics:

1. **Robots.txt Verification**: The scraper engine evaluates `robots.txt` using Python `urllib.robotparser`. Domains explicitly disallowing web crawlers are excluded from HTML scraping.
2. **Request Rate Politeness**: Scraper workers enforce a minimum 3.0-second delay between consecutive HTTP requests to the same origin host.
3. **RSS Priority**: Official RSS/Atom feeds provided by publishers are always used in preference to DOM scraping.

---

## 3. GDPR & CCPA Privacy Compliance

- **User Right to Erasure**: Endpoint `DELETE /api/v1/users/me` purges user credentials, active sessions, and personal identifiers within 30 days.
- **OAuth Token Encryption**: All third-party social media access and refresh tokens are encrypted at rest using **AES-256-GCM** with KMS managed key rotation (`encrypted_tokens` JSONB column in `social_accounts`).
